LA MANZA LOLA — GitHub Pages

1. Crea un repository pubblico su GitHub, per esempio la-manza-lola.
2. Carica i tre file index.html, logo.png e catalogo-es.pdf nella cartella principale del repository.
3. In Settings > Pages seleziona Deploy from a branch, main, /(root), e salva.
4. Il sito sarà disponibile all’indirizzo https://TUO-UTENTE.github.io/la-manza-lola/ (se il repository si chiama la-manza-lola).

Quando pronti, aggiungi catalogo-it.pdf e catalogo-en.pdf; aggiorna i collegamenti nel file index.html.
